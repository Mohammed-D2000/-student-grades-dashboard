# 📊 Student Grades + Attendance Dashboard

This is a beginner-friendly project I created as part of my learning journey in data analysis. It’s a very simple dashboard built using **Python**, **Pandas**, and **Matplotlib**, designed to help me practice working with real data and basic visualizations.

---

## 🔍 What It Does

The script loads a CSV file of student names, grades, and attendance rates. Then it:

- Calculates the average, highest, and lowest grades
- Determines pass/fail status (60 is the passing mark)
- Analyzes average attendance
- Visualizes data using:
  - A bar chart (pass/fail comparison)
  - A pie chart (pass/fail distribution)

---

## 📁 Files Included

- `student_data.csv` – Simple sample data with grades + attendance
- `dashboard.py` – The Python script
- `pass_fail_bar_chart_custom.png` – Bar chart result
- `pass_fail_pie_chart_custom.png` – Pie chart result

## 🚀 How to Run It

1. Make sure you have Python installed.
2. Install the needed libraries:

```bash
pip install pandas matplotlib
```

3. Run the script:

```bash
python dashboard.py
```
